# self-consistent-agents

Monorepo for studying self-consistency in LLM agents.

- `Countdown-Code/` — Countdown reward-hacking environment and verl training (fork of zohaib-khan5040/Countdown-Code).
- `cheatbench/` — agent reward-hacking benchmark (subtree of centerforaisafety/cheatbench).

Sync cheatbench upstream:

    git subtree pull --prefix=cheatbench https://github.com/centerforaisafety/cheatbench.git main
